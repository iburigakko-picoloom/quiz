# ホーム・学習計画・公開版とグループ進捗

2026-10-02。ホーム・計画は端末保存で利用可能。グループ進捗の本番DB適用は追加承認待ち。

## 動作

ホームは今日の全回答回数・連続日数と、計画のdistinct問題数を分けて表示する。共通の開始ボタンは置かない。計画詳細か問題セット詳細で対象・範囲・問題数を確認して既存演習へ進む。折りたたみは保存し、キャラクターOFF設定を維持する。フォルダ検索・並替・追加、計画なしの学習を利用できる。

期限型は作成時の問題内容と対象を固定し、学習曜日・休日と残学習日で未回答を配分する。習慣型は曜日別の目標を使用し、同日の対象内復習は算入、同日の反復は1問として数える。休みの未達分は繰り越さない。日次目標はその日の初回利用時に、日開始前の保存済み回答から計算して確定保存する。アプリを開いていない間に処理を実行したとは扱わない。保存後は同日の回答や同期で目標を縮小しない。

予定の編集は翌日から反映する。休止・再開は当日からで、確定目標は残す。内容編集・対象削除で分母を変更せず、版違い・消失した問題数を表示する。現在版で新しい計画を作る場合、旧計画と回答は保持する。元の期限を自動延長しない。対象版の1周、当日達成、正答率、回答回数、現在の復習状態を混同しない。

学習日のIANAタイムゾーンは端末設定として初回保存し、計画にも個別に固定する。新しい回答には回答時点の内容版と固定学習日を保存する。過去の学習日の再割当はしない。旧ログは固定タイムゾーンで解釈するが、元の端末タイムゾーンが保存されていなかった分は復元不能である。

## 保存・同期

計画は `quizMake:plan:<id>`、確定日次目標は `quizMake:planDay:<id>:<day>` に保存する。IndexedDBの補助レコード・送信待ち・復元可能なlocalStorage投影を同一トランザクションに入れ、既存のCAS差分同期／競合回復と完全バックアップへ含める。端末の一時表示が失敗しても投影を再実行できる。計画の編集は元の値を照合し、別操作の変更を上書きしない。計画編集中と演習中の受信は保護し、入力や対象を差替えない。

実績は保存済み回答ログから導出する。新しい回答の画面反映は保存成功後。編集で旧版ログを削除せず、編集前の内容版を付けて保持し、現在版の復習状態を初期化する。旧版ログを新しい対象版へ合算しない。問題を明示的に削除する既存経路は、その問題の記録削除を維持する。

## 元問題ID・公開版

新しい公開RPCは論理問題IDを受け取り、サーバーが内容のSHA-256版を生成する。公開版はUUIDと不変の問題スナップショットで保存する。同じ内容の再公開では版を再利用する。コピーの新しいローカルIDと元の論理IDを分ける。取り込んだ公開版・元の内容版・取込み時の厳密な内容を保持し、文章一致で由来を推測しない。同じ保存先への未編集の同版再取込みは既存コピーを再利用する。編集済みコピーは保全して別コピーを作る。

旧公開RPCを使った変更は現在版を無効化する。新しい内容を旧公開版の進捗に帰属させない。新RPCが未配備の場合は従来の公開・取込みへフォールバックするが、版不明として共通版進捗には参加できない。古いコピーの元問題IDと公開版は復元しない。端末内計画は利用可能。

## 共有と権限

グループ教材詳細の「みんなの進捗」から、自分が共有するコピーを1つ選ぶ。初期状態は共有OFF。送るのは回答済みdistinct問題数だけで、対象数はサーバーの公開版から決定する。個人計画、生の回答、不要な活動履歴は送らない。本人が編集した内容は除外する。未共有・未取込・更新待ち・反映待ちを0%と表示しない。

新しいテーブルはprivateスキーマでRLSを有効にし、APIロールの直接権限を与えない。限定RPCは `auth.uid()` の本人、閲覧者と対象者の現在の会員資格、教材とグループの現在の関連、共有ON、選択コピーと版、同意世代を確認する。すべての関数で空search_pathと明示的なEXECUTE権限を使う。

共有OFF、会員脱退、教材の関連解除では同意世代を変更し共有を無効化する。古い世代の遅延送信やON再送を拒否する。再加入で自動共有しない。クライアントには共有ONの自動再送待ちを保存せず、反映時に認証とサーバー同意を再確認する。アカウント変更後に旧アカウントの結果を表示しない。

## 検証と限界

ホームの一覧領域を補正：折りたたみ時は犬・全回答回数／連続日数・計画達成を2行の要約にし、計画カードを全て除去して「学習計画 N件・開く」の1行だけ残す。通常の計画は対象・残り・当日数だけの短い2行にする。説明と固定タイムゾーンは学習記録／計画詳細へ移し、短画面の初回は折りたたみを選ぶ。本人が選んだ開閉状態は再読み込み後も優先する。

同じ合成データ、犬ON、同一文字サイズで旧ホーム `b2e43ca` と比較した。360×640の折りたたみは3フォルダを完全表示、4行目も一部表示し、一覧の可視領域は旧287pxに対して296px。390×844の通常表示も3行以上を完全表示する。フォルダ文字サイズは維持し、表示中の操作領域の高さは全て44px以上。開く／畳む、再読み込み、大文字、キャラOFF、短画面の初回状態を実ブラウザで確認し、横はみ出し・未捕捉例外なし。比較画像には旧ホーム、初回公開、補正後を並べる。

最終ローカルチェック：全351件成功、TypeScript/Vite本番ビルド成功。既存未公開同期修正 `d829ebc` と先行差分を保全して取り込み、差分Pullの全Outbox読込回帰を修正した。GitHubの非公開メール保護に対応し、公開用コピーの未公開コミットだけをnoreply作者情報へ変更した。ファイルは同一、元コミットは元の作業コピーとローカルcheckpointに保全している。シャッフルした選択肢の回答も、画面に出した元の問題版に帰属させる（提示順の版で計画判定しない）。
