# Phase 3: 問題作成・とりこみの整理

基準はPhase 1の `b58ae49`。問題・PDF・手書き・学習履歴の保存形式、DB/RPC、インポートの永続保存先は変更しない。

## 実装

- 入口を「作成」（生成AI／手入力）、「とりこみ」（クリップボード／JSONファイル）に分けた。「メモから追加解説を作る」は独立したボタン。
- 「メモから問題を作る」「問題セットのコピー」はその他の作成方法へ移動。「まとめて貼り付ける」はとりこみの下位メニューに残し、既存のテキスト/CSVパーサーを使用。
- AIは指示／資料／過去問を選択してから、依頼や資料 → 作成条件 → 依頼文のコピーの順に下へ表示する。4/5択・任意問題数・複数正解は既存プロンプト生成を再利用。過去問では原文の選択肢数・正解数を維持する。
- 外部生成AIへの依頼とJSONの取り込みは従来どおり分離。資料PDF・過去問PDFは外部AIに添付する操作として示す。アプリ内PDF登録はこの画面に追加せず、保存後の教材の資料管理に残した。既に登録してある資料の参照ID付与は任意で継続できる。
- クリップボードはボタン操作で読み取り、失敗時は通常の貼り付けを案内。JSONファイルは8MB上限と既存スキーマ検証を通して編集可能なレビューを表示。JSON専用経路では不正なJSONをテキスト問題に誤変換せずエラーにする。
- JSONの教材名・出典を未入力の欄に反映する。入力内容を変えたら旧解析結果を破棄し、旧内容を誤って保存しない。
- 従来の問題セットファイルの取り込みも「その他のJSON形式」から保持。新規/編集/コピーの保存前検証、未確定の手入力問題の確認、複数正解、画像・参照ページを含むコピー処理は再利用。
- AIの途中入力は既存account workに段階も含めて保持。ヘッダー戻ると共通screenBackによりAIの前段階へ戻れる。編集/コピー画面の既存退出ガードは維持。
- 補足の小さいグレー説明は追加していない。以前の「先に資料登録をする」補足を削除し、必要な操作ラベルとエラーを表示する。
