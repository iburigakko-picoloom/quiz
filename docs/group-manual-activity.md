# 手動の学習記録

手動記録はグループ内で入力した内容、任意の問題数、本人が入力した分数と日時を共有する。教材IDや問題・回答の内容は送らない。既存の演習セッション集計とは別に保存し、既存の教材別進捗にも混ぜない。自動記録の所要時間は保存していないため表示しない。

`private.quiz_group_manual_activity` は直接参照を拒否し、RLSを有効にする。`quiz_group_manual_activity_publish` は本人、現メンバー、活動共有の有効状態と同意世代を検査する。送信IDは端末に保存し、再送しても同じ記録を二重登録しない。`quiz_group_activity_read_v2` は既存の演習活動と手動活動を共通のID順で返す。閲覧者・投稿者の現メンバー資格と共有世代を確認し、既存の演習活動は教材の公開・現公開版も確認する。旧クライアント用の読取RPCは残す。

送信待ちはアカウント別の端末内IndexedDBに保存し、オンライン復帰・起動・再試行で送る。共有停止や退出でサーバーが拒否した記録は送信せず、端末上で取り消せる。送信前には利用者が共有内容を確認する。手動入力や送信待ちを他の端末の学習同期・バックアップには追加しない。

新しい migration を先に適用して権限を確認してから対応UIを配信する。本番DBは他アプリと共用しているため、既存の非Quizオブジェクトや権限には触れない。PGliteで匿名・部外者・未同意・無効な入力・再送・共有停止と再開・退出と再参加・旧RPC互換・ページ送りを確認。実環境への適用・実アカウントでの送受信は未実施。

実環境の事前advisorでは既存の `private.quiz_group_activity` と同意テーブルにRLS有効・policyなしの情報がある。直接権限を付けず内部関数だけでアクセスする現行設計によるもの。既存環境には他にも警告があり、今回関係しない設定は変更しない。
