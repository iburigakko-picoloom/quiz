# 解説・メモを読みながら資料に書き込む

追加解説画面と追加解説・メモ一覧にも、演習中と共通の右側資料ビューアを追加しました。スマホではヘッダーの「資料」、タブレットでは右端の資料タブから開きます。各Q番号の右にある「移動」は、問題に紐づいた資料ページを直接開きます。紐付けがない問題では無効になり、資料の「参照ページを調整」から設定できます。複数の参照先は資料メニューで選べます。

資料の「写真を追加」から写真を1枚または複数枚選べます。写真は1枚1ページとして既存の資料ファイルへ保存し、PDF・白紙と共通のペン、マーカー、消しゴムが使えます。写真の表示内容と手書きは別の層に保存します。既存の非公開資料同期と完全バックアップの形式・容量枠をそのまま使います。画像の向きを反映し、長辺4096pxまでに縮小、JPEG品質95%で格納します。50MB・500ページ、1枚4000万画素の上限があります。読み込めない形式は選び直しを案内します。資料ファイル生成には[PDF-LIB公式API](https://pdf-lib.js.org/docs/api/classes/pdfdocument)を使い、写真を追加するときに読み込みます。

新しい指の操作は120%まで横スワイプでページ切替、縦操作は拡大部分の移動になります。120%を超える倍率は拡大部分の移動を優先します。ピンチ後に残った指でページが切り替わることはなく、次の操作から切り替えられます。120%までの倍率は次のページにも引き継ぎます。資料を閉じる、参照先を変える、解説編集・取り込みへ進む、戻る操作では書き込みの保存を待ち、失敗時は画面を保持します。

手元のテスト実行と実機操作は利用者の指定で省略し、通常ビルドを確認しました。公開時の既存CIに、120%の境界と写真から生成した複数ページの資料形式・縦横比の確認を追加しました。実機でのペン入力、写真の向き、スワイプの感触は確認が残っています。

メモ入力時は画面全体を縮めず、入力欄だけをキーボード直上へ出します。AndroidのVirtualKeyboard APIが使える場合はメモ入力中だけオーバーレイを有効にし、それ以外はVisualViewportで表示範囲を確認します。読み取り画面・解答パネル・ナビの位置と高さを保持し、キーボード表示直後の自動スクロールを抑えます。利用者が自分でスクロールする操作は妨げません。「完了」、フォーカス移動、画面を離れるときに設定・イベント監視を戻します。本文の下書き保存は既存の処理を維持します。ホームはフォルダ部分だけをスクロールし、学習記録とキャラクターをナビ直上の固定領域に置きます。キーボード設定は[Chrome公式資料](https://developer.chrome.com/blog/viewport-resize-behavior)と[VirtualKeyboard API](https://developer.mozilla.org/en-US/docs/Web/API/VirtualKeyboard_API)に基づきます。実機でのキーボード確認は未実施です。

依頼文のコピーは、非同期の依頼履歴保存を終えてからブラウザのコピーAPIを呼ぶ方式を改めました。タップの中で`ClipboardItem`へ準備完了を待つPromiseを渡し、保存成功後の正確な全文だけをクリップボードへ書きます。保存失敗はコピー成功にせず、同じ依頼IDの全文を保持して再コピーできます。未対応・拒否のときは「もう一度コピー」「全文を選択」と選択可能な全文を表示します。単独メモにもコピーボタンを追加しました。タップ内での書き込みとPromiseの扱いは[WebKit公式資料](https://webkit.org/blog/10855/async-clipboard-api/)に基づきます。実機のタブレットでの確認は未実施です。
