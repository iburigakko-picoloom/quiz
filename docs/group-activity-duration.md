# 演習画面の表示時間

統合時の追記: 2026-11-08に本番migrationを適用し、privateテーブルと公開RPCの権限を確認した。実端末での検証は未実施。

各問題を表示している間だけ単調時計で時間を計測し、画面が非表示・ページ退避中の時間を除外する。ネイティブ端末ではアプリの前面状態も確認し、状態が取得できない間は計測しない。アカウント切替中も計測しない。保存済み回答と一致する問題だけを教材ごとに合算する。時刻の逆行、不完全な復元、旧データなどで正確な値を確認できない場合は時間を送らない。時間は「演習画面の表示時間」であり、操作や集中の有無を測るものではない。

時間の共有は活動共有とは別に初期OFFとし、グループごとの明示的な同意が必要。送信前に各グループの共有設定を取得し、同意より前に始まった時間を送らない。サーバー側でもメンバー、公開状態、活動同意、時間同意の世代と開始時刻を再確認する。時間の共有停止・活動共有停止・退出時は世代を更新し、古い時間が再同意時に再表示されないようにする。件数の共有は維持できる。旧版や未計測のイベントは時間なしのまま。

計測値の問題IDは端末内の作業状態に限り、送信時は教材単位の秒数にまとめる。保存済み回答に結びつかない問題や内容変更済みの問題の時間は送らない。Outboxの最初の送信内容を固定し、再試行・画面復元で別の時間に置き換えない。

本PRは手動記録PR #37のDB・タイムラインに依存する。新しい migration を先に適用し、既存の活動RPCと過去データを維持したうえでUIを配信する。本番DBと実端末での検証は未実施。Androidの画面退避・復帰がWebViewのvisibilityイベントに反映されることを実機で確認する必要がある。
