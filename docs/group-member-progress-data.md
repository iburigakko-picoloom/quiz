# メンバー別教材進捗の一括取得

概要で選択したメンバーについて、教材ごとの共有済み進捗を1回のRPCで取得する。自分を選んだ場合は従来の端末内進捗を使う。別の人を選ぶと前の結果を表示せず、遅れて返った別の人の応答も破棄する。フォーカス復帰・オンライン復帰・10秒ごとに更新し、失敗時は値を消して再試行できる。

`20261107172840_group_member_material_progress.sql` はテーブルや既存データを変更せず、`public.quiz_group_member_material_progress(group_id, member_id)` と内部の同名処理を追加する。公開関数はsecurity invoker、内部はsearch_path固定のsecurity definer。認証、閲覧者・対象者の両方の現メンバー所属、グループと教材の現在の関連を確認する。対象者が明示共有し、同意世代と公開版が一致し、集計済みのときだけ回答済み数・母数・Level・反映日時を返す。それ以外は未共有／更新待ち／反映待ちとnullを返す。問題文・回答内容・非共有値を返さない。

既存の `(group_id,set_id,user_id)` 主キーとグループ教材のキーを利用し、教材ごとの追加HTTP要求は行わない。選択者がグループを離れた場合も取得しない。共有停止、共有再開後の旧世代、別公開版、教材解除、匿名・部外者の拒否と、読み取りでデータを書き換えないことをPGliteの実SQLで確認する。

このブランチはUI修正PRを基準とする別レビュー単位。migrationは本番に適用していない。リリース時はDBを先に追加し、RPC権限・実環境のadvisorsとグループ実アカウントでの確認後に対応UIを配信する。ロールバックする場合も既存テーブル・進捗は削除しない。ローカルSupabaseのadvisorsはPostgres/Dockerが未起動のため実行できず、PGliteの権限・RLS相当のSQL検証を実施した。
