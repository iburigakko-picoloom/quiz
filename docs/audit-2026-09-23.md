# Quiz Make 操作・保守性・動きの監査

## 修正内容

| 観点 | 確認した問題 | 修正 |
| --- | --- | --- |
| 誤操作 | 資料・フォルダ追加・問題セット・詳細解説・バックアップのメニューが外側タップで閉じない | `ActionMenu` に統一。外側タップ、Esc、Tabで外へ移動、項目選択で閉じる |
| 操作性 | 確認画面の保存中→完了後、フォーカスが枠に残るとTabが背面へ抜ける | 保存終了時のフォーカス復帰と、枠・背面からのTab移動を修正 |
| 小画面 | 確認内容が長い場合、ダイアログが画面の高さを超える | 最大高さと内部スクロールを設定。全画面確認は既存の表示を維持 |
| 処理量 | 問題ごとに全進捗を検索し、問題数×進捗数の探索になる | 進捗を一度だけMap化。削除対象の照合もSet化。対象や削除範囲は変更しない |
| 重複 | 登録順・ランダム・復習の開始処理、復習候補の処理が重複 | 共通の開始処理と既存quiz utilityに集約。分野分類は画面間依存をなくしてutilityへ |
| 重複CSS | 確認画面が暗色定義→全体CSS→最終CSSで上書きされる | 現在の白背景・青系UIを保ってConfirmDialog.cssに集約 |
| 動き | 資料の引き出し中、pointermoveごとにPDFを含むReactツリーを再描画 | requestAnimationFrameで1フレームに1回、共有CSS変数だけを更新 |
| 動き | メニュー・確認画面が突然現れる | 160〜200msの控えめな表示アニメーション。操作待ち時間は追加しない |

新しいアニメーションは `prefers-reduced-motion` を尊重する。資料の手書き保存を待ってから移動・閉じる仕組みは残す。

## 変更しないもの

- AppData version、保存キー、ID、問題・メモ・資料の形式。移行処理なし。
- 学習済み設定、復習間隔、曖昧問題の優先、正答・誤答の扱い、選択肢のランダム化。
- 同期先、クラウドDB・権限、バックアップ内容、上書き前の比較・復元保護。
- 既存の未コミット変更は取り込まず、今回の修正だけを公開対象にした。

## 確認

- 作業開始時の既存テスト：229件成功。
- 作業中ツリー：231件成功、選択肢ランダム化6件成功。
- 公開する差分だけを取り出したツリー：246件成功、TypeScriptを含む本番ビルド成功。
- 新規の常設テストは2件のみ。分野・Level・復習の結果と非破壊性、5,000問での線形探索を確認。
- 「開始処理が3か所にあること」だけを調べていた古いテスト1件は削除し、実際の選択結果のテストで置き換えた。
- 独立した一時Chromeプロファイルで360px・430px・1024pxを確認。フォルダ→問題セット→演習、資料開閉、ページ変更、詳細解説、外側タップ・Esc、横はみ出しを確認。
- 360×640pxで確認画面の保存中・完了後、Tab/Shift+Tab、閉じた後のフォーカス復帰、長文スクロール、動きを減らす設定を確認。
- 同期競合、保存失敗、ロールバック、資料参照、PDF同期、バックアップ復元、JSON読込、共有画像は既存の回帰テストで確認。実ユーザーの保存データは操作していない。

## 残る確認・見送った変更

- iPhone/iPad実機のキーボード、ピンチ・ペン入力、実際の2台同時同期・回線断は今回のChrome検証だけでは保証できない。
- 本番アカウントのLINE認証やクラウド書き換えは行っていない。
- ビルドには従来からの大きな初期JSチャンクと、cloudServiceの静的/動的import混在の警告が残る。機能を守るため、今回まとめて分割・依存更新はしていない。
- App.tsx、同期処理、手書き処理は大きいが、行数だけを理由に分割すると競合制御や保存待ちを壊しやすい。今回確認できた重複と無駄な探索に絞って整理した。
