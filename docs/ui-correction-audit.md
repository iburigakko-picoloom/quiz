## 現在の実装・検証状況

- H01: 複数教材の索引を最大4件並列で読み取り、資料名／教材名の検索、所有教材・資料・ページIDを既存ビューアへ渡す。参照資料の探索を所有教材に限定。戻る際の検索・スクロール位置を復元。サブ端末は一覧のみ表示。PDF・手書きは複製しない。
- G01/G02/G06: 歯車への設定入口、集計帯削除、共有状態によらない参加者名・役割一覧。共有済み統計は別の開閉領域に保持。
- G03: 自分とグループ全体の2組のグラフを同じカードに並べない。メンバー選択は未実装。
- T01: 活動を日付見出しと行に変更し、同意と再送を設定欄に保持。
- ビルド成功。関連61テスト成功。資料一覧の実Appブラウザ検証は別教材、検索、対象資料、ブラウザ戻り、スクロール復元、サブ端末、320/360/390/768幅を確認。グループは管理・招待・資料公開・共有同意・再送・戻る先をブラウザで検証。
- 添付v2.1と390px実画面を目視。データ件数・状態を揃えた両幅比較は未完了。実Android実機は未確認。
