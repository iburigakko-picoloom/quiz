## 演習中の関連問題の別ブランチ

演習を中断せず、資料ドロワーの関連問題から既存の問題詳細を読み取り専用で開く。詳細を閉じると同じ資料ページと演習に戻る。表示だけでは回答や進捗を追加しない。別の問題の演習をその場で開始する操作は実装していない。
実Appで詳細の戻るボタン、ブラウザ戻る、資料ページID、回答履歴が増えないことを確認。実Android/iOS端末は未確認。

通常の資料画面から関連問題の詳細を開いた場合は、その問題の演習を開始できる。解答・結果を経て問題詳細へ戻り、さらに戻ると同じ資料ページに復帰する。演習中のドロワー内で別の演習を重ねて開始する操作は未実装。
