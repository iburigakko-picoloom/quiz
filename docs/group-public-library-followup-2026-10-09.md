## 公開削除の範囲

以前は公開解除とフォルダから外す操作だけでした。公開フォルダと問題セットに「公開から削除」、自分の公開に「削除済みの公開 → 非公開で復元」を追加します。

* フォルダを削除すると、そのフォルダと専用のセットが検索結果から消えます。別の公開フォルダにあるセットは残ります。
* 単独公開は独立した公開先です。既定で保持します。確認画面に対象数を出し、「単独公開中の N セットも削除する」を選んだ場合だけ、他の公開フォルダにない単独公開分も削除します。
* 旧版から移行したセットは単独公開とフォルダ公開が共存することがあります。どちらが意図された公開かを推測して消さず、上記の確認で選べます。
* セットを直接削除すると、単独公開とすべての公開フォルダから消えます。グループ共有、所有者の元教材、既存の取り込みコピー・学習履歴・公開版は残ります。
* 復元は非公開です。フォルダは改めて公開を再開できます。直接削除したセットのフォルダ参照は自動で再公開せず、追加／公開を明示して行います。

公開カタログからの削除であり、既存の共有リンク・グループ権限・他人の保存済みコピーを撤回する機能ではありません。内容の全消去を示す文言にはしていません。

## サーバー保護

既存 `quiz_public_folder_manage` RPC に所有者限定の削除／復元アクションを追加し、既存 RPC の署名・実行権限は変更しません。フォルダ・所属に nullable な `deleted_at` と、非公開 RLS テーブル `quiz_public_deleted_sets` を追加します。新しい外部実行権限・資格情報は作りません。

検索・閲覧・人数／問題数・カテゴリーは有効な参照だけを使います。同一所有者の公開先変更はトランザクションロックで直列化し、確認時の更新日時と所属セット集合が変わった削除を拒否します。復元も削除日時を照合します。再実行は冪等です。

削除時にローカル公開キューを取り消し、サーバーも削除済みフォルダへの add / ready / publish と、削除済みセットの単独公開を拒否します。遅延した旧クライアントの書き込みにもトリガーが効きます。グループだけの内容更新は続けられます。競合・復元必要・通信失敗は確認画面や公開キューで原因と次の操作を示します。
