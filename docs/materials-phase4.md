# Phase 4: 資料一覧・PDF検索・関連問題

基準: Phase 1 `b58ae49`。既存のPDFビューア、ページID、手書きの保存境界を再利用している。

## 実装

- `MaterialsPanel`: 左資料一覧を開閉。資料/関連問題タブで切替。canvasは関連問題表示中もマウントを保持し、変更前に既存`run`→`flush`を通す。現在の問題セットの資料範囲と、既存の別セット参照時の範囲制限を維持。
- `MaterialNavigator`: 登録資料名の検索、現在のPDFのテキスト検索、キャンセル、結果ページへ移動。結果は最大200ページ表示し、超過は明示。改行/全角/小文字化で照合し、日本語等の分割text itemにも対応。
- `MaterialRelatedQuestions`: materialIdとpageIdの両方に一致する問題を表示。問題本文/選択肢から「参照PDFページへ」で戻れる。未紐付けページは0問表示。
- `materialSearch`: PDF.jsの`getTextContent`を順番に読み、PDF元ページ番号を既存material pageIdへ対応づける。白紙ページを検索対象から除外し、挿入・並べ替え後の画面ページ番号と安定IDを保つ。抽出可能テキストがないPDFと、検索語が見つからないPDFを区別。混在PDFでは抽出不能ページ数を表示。OCRは追加していない。
- `MaterialsDrawer` / `NoteListScreen`: 既存の質問・参照データを関連問題表示へ接続。新しい保存形式やDB変更はない。

## データ保護

テキスト検索は一時的な読み取りのみ。抽出文、検索語、個々の回答をサーバーや同期ストレージへ保存しない。検索終了/中止/資料変更時にPDFタスクを破棄する。資料移動・ページ移動・関連問題への切替は既存の手書きflushに成功した場合だけ実行。PDFと手書き原本は編集しない。

ブラウザ検証は隔離fixture、ネットワーク遮断で実施。実ユーザー資料や本番DBは使用していない。検索は抽出可能なテキストのみを対象とし、画像へのOCRや検索語のページ上ハイライトは対象外。既存の100MB/2000ページ上限を維持し、全ページ検索は途中キャンセル可能。

## 配信

DB migration不要。既存データ移行不要。アプリ更新だけで追加機能を利用できる。旧アプリへ戻してもPDF・手書き・参照形式に変更はない。
