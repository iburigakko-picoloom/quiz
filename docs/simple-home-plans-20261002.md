# ホームと計画作成の簡素化

## 画面の変更

ホームを白背景に統一し、「今日のがんばり」を常時表示する。折りたたみ操作と旧表示設定への依存を除去した。古い`quizMake:homePreferences`は削除せず、保存・同期済みの値があっても実績を隠さない。犬とOFF設定、全回答回数・連続日数・計画の達成、学習記録への入口を保持する。

「がんばり→フォルダ→計画」の順序を保持する。フォルダの検索・並び替えは、その名前の入口から必要時に開く。教材検索とフォルダ追加の入口はそのまま。ホームの計画は名前と今日の進捗に絞り、対象や範囲の確認・演習開始は既存の計画詳細で行う。

計画作成で最初に表示する入力は、問題集と期限、または問題集と毎日の問題数。期限までに1周する目的と習慣を同じ選択欄に置く。計画名は空欄なら問題集名を使い、分類・範囲・曜日別目標・休日・タイムゾーンは任意の詳細に置く。保存前の確認には対象問題集、範囲、問題数、期限または量、固定する学習日のタイムゾーンを表示する。

既存計画の編集では、名前、固定対象・版、タイムゾーン、曜日別の問題数と休日を引き継ぐ。今日の目標は変更せず、予定変更は従来どおり明日から反映する。保存・同期・同時編集保護の処理は変更していない。

## 検証

隔離したChromeと合成データを使用。390×844、360×640、ルート文字サイズ24pxで白背景、常時表示、水平はみ出しがないこと、44px以上の操作対象を確認した。がんばり欄は390pxで約103px、360pxで88px、大文字で109px。犬OFFでも実績は表示する。

旧collapsed=trueを保存した状態で再表示、フォルダ検索・並び替えの開閉、学習記録とフォルダへの往復を確認した。期限型・習慣型を最小入力で保存し、名前の自動補完、対象40問、期限と毎日12問の反映を確認した。既存計画と回答ログを保持し、既存の曜日別目標・休日・名前・対象・タイムゾーンを閉じた詳細のまま編集保存して保持することを確認した。

全体チェックで既存の同期テスト1件が実行時刻に依存して失敗した。回答履歴の日時だけを後から差し替えると、復習の遷移は実行時刻で決まっていた。テストのDateを各イベント時刻に固定し、回答と復習状態を同じ時刻から作るように直した。同期の実装と既存の検証条件は変更していない。
