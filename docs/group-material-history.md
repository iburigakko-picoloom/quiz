# 教材ごとの学習記録

教材の詳細を開いたときだけ `quiz_group_material_activity_history` を呼び出す。既存の演習セッション記録を、現在の公開版に限定して最大50件ずつ読み取る。個々の問題や回答は返さない。学習時間は保存されていないため表示しない。

RPCは呼び出し元と投稿者の現在のグループ所属、教材の紐付け、活動共有の同意と同意世代、公開版、投稿の無効化状態を確認する。共有停止・退出・公開解除・公開版変更後の古い投稿は表示しない。権限がない場合はエラー、公開版が異なる場合は更新待ちを返す。既存のテーブルやデータは変更しない。

DB migration を先に適用した後、対応するUIを公開する。旧クライアントのRPCは変更しない。適用前に実環境の権限診断を行う。ローカル環境にDockerがないため Supabase advisor は未実行。本変更は本番DBへ未適用。

手動記録と演習時間の保存・共有は対象外。時間を既存の回答日時から推測しない。
