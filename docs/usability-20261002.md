# 操作改善と簡素化（2026-10-02）

## 実装の区切り

ホームの「がんばり→フォルダ→計画」はPR #9、公開SHA `13368523d48878547804eb97cb8f354d32196841`。公開16ファイルと配備成果物の一致、390px通常・360px折りたたみの順序とスクロールを確認済み。

問題内容の編集時に旧回答を保持し、旧版の内容を `questionRevision` と固定計画のスナップショットに残す処理は既修正。変更後の正解へ旧成績を足さず、現在版の復習状態だけ初期化する。この処理を重複させない。編集画面の説明は、その教材に該当する固定計画と共通版進捗への影響を表示する。

個人教材検索の画面は存在したが、Appの `search` 遷移が公開検索へ置き換えられていた。個人教材検索を接続し、ホームのフォルダ見出しに小さい入口を置く。公開検索との区別、検索条件、教材・問題IDによる戻り位置とフォーカスを維持する。大量結果は100件ずつ表示する。

手動取込で保存を遅延させた実画面再現では、ブラウザ戻るで取込画面を離れ、完了後にフォルダへ勝手に移動した。画面内戻るとブラウザ戻るを同じ終了ガードへ接続する。現在保存中の1件は完了を待ち、残りを中断し、保存済み項目をキューから除いて再開する。完了遷移は本人が「保存先を開く」を選んだ場合だけ行う。未保存入力の再開は同じアプリの実行中に限る。アプリを閉じる前は元ファイルを保管する旨を表示し、入力がある間はブラウザ終了を警告する。

## 削除取り消しの範囲

今回まず実装するのは、作成・一括編集の下書き問題のUndo。削除した1問と隣接する下書きIDだけを保持し、その1問だけ戻す。削除後に編集・追加・並べ替えたほかの問題を戻さない。重複IDを追加しない。保存済みデータ・画像・ノート・同期の削除を取り消したとは表示しない。

## 保存済み教材の復旧設計（実装前に提示）

保存済み教材は、既存の削除処理がノートの削除、画像の掃除、同期の削除レコードを伴うため、下書きUndoと同じ処理では戻せない。AppData全体の過去スナップショットを戻す方法は採用しない。

候補は「削除対象だけの端末内ごみ箱」。削除前に対象のフォルダ／教材／問題、関連する回答と復習、対象だけのノート、画像ファイルを専用の復旧記録へ保存して検証し、その後に既存の削除を実行する。記録の保存に失敗した場合は削除せず、本人へ再試行を案内する。保存成功の後でも、既存の削除が失敗したら復旧記録を「削除未完了」として残し、削除済みと表示しない。

復元は対象IDごとの最新状態と削除時の版を比較し、現在存在する教材、別の操作で編集されたノート・画像・回答、他のフォルダへの移動を上書きしない。元IDに別の更新がある場合は、自分の教材として新しいコピーへ復旧する案を提示する。公開設定と共有進捗の同意を復旧記録からONに戻さない。共通版の由来だけを保ち、個人計画の付け替えは影響を確認して明示的に行う。

同期へ既に送られた削除は、復旧を新しい変更として送る。送信待ち旧データの再生やクラウド全体の巻き戻しはしない。アカウント・同期接続が変わった場合は旧接続へ送らない。添付画像がクラウドでも削除された場合は、端末内ごみ箱に保持した実ファイルを検証してから新しい画像レコードへ登録する。

着手前に、ごみ箱の保持期間・容量上限、元IDを復元できない場合の新コピー、他端末へ反映済みの削除の復旧表示を確定する。保存済み教材のごみ箱はこの段階では未実装。実ユーザーデータを検証用に削除しない。本番DBの変更も行わない。

## 維持する条件

5つの下部メニュー、犬とOFF設定、全回答実績と計画のdistinct達成の区別、ホームの折りたたみ保持を維持する。音・新しい演出は追加しない。全体公開・グループ共有・自分の教材の保存先と公開範囲は変更せず、用語だけを整理する。

端末内復旧コピーとファイル保存を区別し、端末内コピーだけでは故障・紛失に備えられないと明示する。接続診断へ技術情報をまとめる一方、未送信・失敗・OFF・競合・再試行と、変更ごとの同期／全体コピー同期の違いを残す。

## 検証記録

隔離したChromeと合成データだけを使用。既存ユーザーの保存データや本番DBを検証のために変更していない。

- 必須全体チェック359件成功。テスト並列数は2。最初のPWAテストのWindows一時フォルダ権限エラーは、許可されたテスト環境で再実行し、最終全体チェックでも成功。
- 問題編集で旧回答16件、旧内容版、固定計画40問を維持。新しい内容の成績は0へ初期化。保存失敗時は入力を維持。
- 一覧の分類・Level順・問題ID・フォーカスを保持。分類を変更した問題への戻り位置の差は0.5px。
- 390pxと360px、ルート文字サイズ24pxで教材検索、全文表示、バックアップ、一括編集を確認。検索とバックアップの操作対象は44px以上、横方向のはみ出しなし。
- 200問の一括編集で2・121・200問目の要確認へ順に移動。別の問題の入力を維持して200問を保存。ヘッダーの保存と下部の保存の両方を使用可能。
- 下書きUndoは削除対象だけを戻し、削除後の別の編集を維持。直近20回を保持。
- 新規フォルダへの3ファイル取込で、ブラウザ戻るのキャンセルと画面戻るの中断を確認。1件の保存を待って戻り、同じフォルダへ残り2件を再開。重複と完了後の自動遷移なし。
- 公開検索はローカルURLの模擬応答を使用。初回待機、失敗時の前回結果保持、再試行成功の0件、応答順の逆転を確認。本番Supabase接続の検証ではない。
- 端末内復旧コピー作成、JSONファイルの実保存と形式検証、不正ファイルの復元失敗時の現データ保持を確認。
- 教材検索の表示は100件ずつ。500教材・20,000問の合成データで索引作成40.8ms、検索10回中の最大5.8ms（このPCの検証ブラウザでの測定。端末ごとの速度保証ではない）。

本番DB適用、実アカウントの共有進捗、保存済み教材のごみ箱は未実施。取込の未保存入力は同じアプリの実行中に再開でき、再起動をまたぐ入力保存は対象外。保存済みの教材は通常の端末保存へ確定する。
